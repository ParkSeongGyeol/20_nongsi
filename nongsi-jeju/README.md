# 농시 제주 — 발표 시연용 웹 MVP

농시 제주는 제주 농가와 농촌인력중개센터를 위한 **기상 기반 농작업 일정·인력 배치 최적화 서비스**입니다. 실제 AI·공공데이터 API·백엔드 없이, 발표 화면과 짧은 시연에 적합한 현실적인 데모 데이터와 상태 전환을 구현했습니다.

## 실행

Node.js 24 LTS 환경을 권장합니다.

```bash
npm install
npm run dev
```

브라우저에서 `http://localhost:5173`을 엽니다.

프로덕션 빌드와 미리보기:

```bash
npm run build
npm run preview
```

## 핵심 화면

| URL | 화면 | 발표 핵심 메시지 |
| --- | --- | --- |
| `/` | 오늘의 작업 | 비가 오기 전 무엇을 먼저 해야 하는지 한눈에 판단 |
| `/schedule` | AI 최적 일정 | 기상 작업창·인력·장비·이동시간을 반영한 추천 순서 |
| `/calendar` | 연간·주간 계획 | 연간 계획, 주간 기상 조정, 당일 재계획의 연결 |
| `/farms` | 농장 관리 | 농지·작물·작업·자원의 통합 관리 |
| `/center` | 운영센터 | 농협·인력중개센터에 제공하는 기관형 B2B 운영 화면 |
| `/records` | 작업 기록 | 완료 결과와 음성 입력을 구조화해 다음 추천에 반영 |

## 권장 데모 시연 순서

전체 흐름은 약 3분입니다.

1. `/` 대시보드에서 상단 KPI와 **“오늘 모든 작업을 완료할 수 없습니다”** 경고를 설명합니다.
2. 농지 작업카드 A·B·C·D를 선택하며 우선순위 점수, 기상 적합도, 지도 동선이 함께 바뀌는 것을 보여줍니다.
3. **AI 일정 생성**을 눌러 분석 로딩 후 `/schedule`로 이동합니다.
4. A과원 방제, B밭 관수, C밭 정식 카드를 눌러 우측의 상세 계산 근거를 비교합니다.
5. 우측 상단 **기상상황 변경 시뮬레이션**을 누릅니다. 강수 접근 4시간→2시간 10분, 풍속 4.8→6.2m/s, 강수확률 30→80% 변화를 확인합니다.
6. 경고 모달에서 **일정 다시 계산**을 누릅니다.
7. 변경 전·후 비교에서 다음 변화를 강조합니다.
   - A과원 방제 10분 앞당김
   - B밭 관수 자동 취소
   - C밭에 작업자 2명 재배치
   - D밭 생육 확인 다음 날 연기
   - 예상 완료율 60%→80%, 예상 대기시간 70분→25분
8. **오늘 일정 확정**을 눌러 작업자 공유 알림을 확인합니다.
9. **작업 완료 기록으로 이동** 후 **A과원 작업 완료 처리**를 누릅니다.
10. **음성 입력 시작**을 눌러 자연어 작업 메모가 작업·시간·인원·특이사항으로 구조화되는 모습을 보여준 뒤 저장합니다.
11. 사이드바의 **운영센터**로 이동해 기관형 비즈니스 모델을 설명하고 **자동 배치 실행**을 누릅니다. 배치 완료가 22명→25명, 미배치 요청이 4건→2건으로 변합니다.
12. **주간 계획**에서 연간/주간 탭을 전환해 장기 계획과 단기 기상 조정이 연결됨을 보여줍니다.
13. 상단 **데모 초기화**를 누르면 모든 상태가 처음으로 돌아갑니다.

## 구현된 상호작용

- AI 일정 생성과 지연 로딩
- 기상 변화 감지 모달과 실제 일정 재계산
- 변경 전·후 일정 및 성과지표 비교
- 작업 선택에 따른 상세 우선순위 근거 패널
- 오늘 일정 확정
- 작업 완료 및 음성 입력 구조화 시뮬레이션
- 농가용/운영센터 화면 전환
- 연간/주간 캘린더 전환
- 센터 작업자 자동 배치, 일괄 전송, 농가 알림, CSV 다운로드
- 어느 화면에서나 가능한 데모 초기화
- 브라우저 뒤로가기와 직접 URL 진입을 지원하는 History API 라우팅

## 검증

```bash
npm run lint
npm run build
npm run smoke
npm audit
```

`npm run smoke`는 로컬 Chrome 또는 Edge와 `http://127.0.0.1:4173`의 미리보기 서버를 사용해 다음 흐름을 자동 확인합니다.

`AI 생성 → 기상 재계산 → 일정 확정 → 완료 기록 → 센터 배치 → 캘린더 전환 → 초기화`

## 데이터와 표현 원칙

모든 수치와 기상정보는 발표용 시연 데이터입니다. 화면 하단에 기상청 초단기·단기예보, 레이더, AWS, 농촌진흥청, 제주특별자치도 공공데이터의 활용 구조를 명시하되 실제 API 연결로 오해하지 않도록 안내 문구를 표시했습니다. 추천 결과는 의사결정 지원 정보이며 최종 결정은 농가 또는 운영 담당자가 수행합니다.
