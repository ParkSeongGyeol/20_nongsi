# 하드웨어 안전과 Phase 2

`firmware/esp32-sprayer`에는 실제 센서 없이 Python 시뮬레이터와 동일한 JSON을 보내는 ESP32 펌웨어가 있습니다. 컴파일 검증까지만 수행하며 실제 보드 업로드, 센서 펌웨어와 회로는 아직 검증 완료로 표시하지 않습니다.

## 안전 조건

- 실제 농약을 사용하지 않고 저전압 물 펌프만 사용합니다.
- 실제 방제기, 고전류 부하, 배관에 바로 연결하지 않습니다.
- 펌프 정격 전압/기동전류, 전류센서 측정범위와 절연, 압력센서 전원/출력전압/나사 규격/사용 유체를 먼저 확인합니다.
- ESP32 ADC 입력은 허용 전압을 넘기지 않으며 모터 전원과 로직 전원의 접지·노이즈·역기전력 대책을 검토합니다.
- 릴레이만으로 DC 모터를 직접 구동하지 말고 부하 정격에 맞는 드라이버, 퓨즈, 플라이백 보호를 설계합니다.

## 연결 전 필요한 실제 사양

1. 데모 펌프 모델명, 정격 전압, 정상/기동 전류
2. 전류센서 모델과 출력 범위
3. 압력센서 모델, 전원, 출력, 최대압력, 물 사용 적합성
4. MPU6050 보드의 로직 전압과 I2C 주소
5. 사용할 전원공급기의 정격과 보호회로

## 단계별 단독 검증 순서

1. ESP32가 시뮬레이터와 동일한 JSON을 MQTT로 송신
2. MPU6050 I2C 스캔과 정지 상태 원시값 확인
3. 진동 RMS만 계산해 전송
4. 물 펌프는 분리한 채 버튼으로 `pump.is_running` 가상 신호 전송
5. 전류센서를 무부하/알려진 저전압 부하로 보정
6. 물 전용 압력센서를 안전한 압력원에서 보정
7. 각 센서를 합친 뒤 물 펌프 데모

실제 부품 사양이 확정되기 전에는 핀 번호나 배선도를 확정하지 않습니다.
